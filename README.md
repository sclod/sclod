## Чому тут мало коду

Основні комерційні проєкти — це внутрішні системи замовників. Їхній код і дані не підлягають публікації, тому в публічному доступі їх немає і не буде.

Те, що можу показати відкрито, викладаю окремо — як санітизовані демо з вигаданими даними:

> ### [→ vehicleflow-demo](https://github.com/sclod/vehicleflow-demo)
> Full-stack демо трекінгу замовлень: публічний сайт, клієнтський трекінг замовлення з етапами доставки, адмінка з авторизацією по сесійній куці, керування лідами та їх конвертація в замовлення.
> Next.js · TypeScript · Prisma · SQLite · Leaflet · e2e-тести на Playwright.

Архітектуру, схему даних і прийняті рішення по закритих проєктах готовий детально розібрати на співбесіді — без коду й даних замовника.
