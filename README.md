Python, PostgreSQL, Linux. На вебі TypeScript / Next.js.

Роблю внутрішні системи для бізнесу: CRM, інтеграції з державними реєстрами, збір і обробка даних, телеграм-боти.

Відкритий до пропозицій: backend, автоматизація та інтеграції, аналітика даних. Київ або віддалено.

### Що працює в проді

**CRM для юридичної практики** · з 2023, зробив з нуля і далі веду сам

- інтеграція з Єдиним державним реєстром судових рішень: архів 320 МБ у ZIP і 1,7 ГБ розпакованого, читаю потоком без розпакування на диск, у памʼять потрапляють лише потрібні рядки
- життєвий цикл справи: статуси, дозволені переходи, автоматичні дії при зміні статусу
- ролі `ADMIN` / `OPERATOR` / `VIEWER`, розмежування доступу до записів, audit log і історія змін
- 26 REST-роутів, вхід і нагадування через телеграм-бота з перевіркою підпису подій
- перед виливкою unit-тести і smoke-сценарій
- розгортання і супровід на собі: Linux, Nginx, PM2, резервні копії, розбір інцидентів по логах

Python · PostgreSQL · Prisma · Redis · Next.js · TypeScript

**Бот збору й фільтрації вакансій** · 2026, працює на моєму сервері

- чотири джерела: офіційний RSS, два JSON-ендпоінти і державний портал
- зведення в одне, прибирання дублів між джерелами за парою «назва плюс компанія»
- відбір за правилами, де по кожному запису видно причину рішення, а не чорна скринька
- інтерфейс у Telegram: жодна дія не відбувається без підтвердження людиною
- коли одне джерело заблокувало IP за частоту запитів, переміряв навантаження, скоротив його в 13 разів і розвів джерела так, щоб відмова одного не зупиняла збір
- тести: 21 на правила відбору, 38 сценарних, окремі на розбір даних

Python на стандартній бібліотеці · SQLite · pm2

**Телеграм-боти для бізнесу** · 2023 до 2024 · Python, aiogram

Найцікавіший: бот для рієлторської компанії. Підтягнув базу обʼєктів, зробив каталог нерухомості й велику систему фільтрів, по факту замінив їм сайт. Були й боти-магазини: каталог, кошик, повний сценарій замовлення, стани діалогу.

Комерційні проєкти це внутрішні системи замовників. Ні код, ні дані викладати не можу.

Що можу показати, виношу окремо, почищеним і з вигаданими даними:

**[vehicleflow-demo](https://github.com/sclod/vehicleflow-demo)** · трекінг замовлень авто. Публічний сайт, кабінет клієнта з етапами доставки, адмінка з авторизацією, керування лідами. Next.js, Prisma, e2e-тести на Playwright.
